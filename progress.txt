## Codebase Patterns
- Use `python-docx` `Document` with `BytesIO` buffer for in-memory DOCX generation
- Use `fpdf2` subclassing `FPDF` for PDF generation; prefer `cell()` with `new_x="LMARGIN"` / `new_y="NEXT"` over `multi_cell()` for simple text
- When registering a new API router in `main.py`, add both the import and `app.include_router()` call
- Export module follows: define exporter in `src/export/`, add endpoint in `src/api/export.py`, add tests in `tests/`
- Database models follow `QuizAttempt` pattern: UUID PK, FK to users, standard timestamp fields
- No migration needed — `Base.metadata.create_all` in `init_db()` handles table creation
- Schema files follow `SchemaModel` base from `src/schemas/base.py`
- The Ralph system stores the active PRD at `scripts/ralph/prd.json` and archives old ones
- Dashboard API rewrites go in `dashboard/next.config.js` under the `async rewrites()` section — add the path before committing
- Dashboard pages follow patterns: `'use client'`, `fetchWithTimeout` from `@/lib/fetch`, lucide-react icons, Tailwind CSS custom theme (bg-card, border-border, etc.), `useState` for state management
