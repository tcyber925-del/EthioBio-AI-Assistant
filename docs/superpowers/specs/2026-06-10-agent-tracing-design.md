# Agent Tracing — Design Spec

**Date:** 2026-06-10
**Status:** Draft
**PRD:** PRD-009 — Agentic RAG Governance, Evaluation, and Observability (sub-project 3)

## Overview

Persistent trace storage and API for the Agentic RAG pipeline. Every pipeline execution produces a trace (already captured in-memory by `PipelineMonitor`); this sub-project persists traces to PostgreSQL and exposes them via REST API.

**Scope:** API-only (no dashboard UI). In-memory metrics from `PipelineMonitor` remain unchanged.

## Architecture

```
PipelineMonitor (in-memory, real-time)
     └─ on_complete callback → TraceRepository.save_trace()
                                    │
                            PostgreSQL (agent_traces table)
                                    │
                            REST API (/traces endpoints)
```

- `PipelineMonitor` stays in-memory for rolling metrics
- `TraceRepository` provides async CRUD over PostgreSQL
- REST API layer reads from `TraceRepository`

## Data Model

### PostgreSQL: `agent_traces` table

| Column | Type | Notes |
|--------|------|-------|
| `trace_id` | VARCHAR(64) PK | Generated by PipelineMonitor |
| `start_time` | TIMESTAMPTZ | Trace start |
| `end_time` | TIMESTAMPTZ | Nullable (running traces) |
| `status` | VARCHAR(16) | `running`, `completed`, `failed` |
| `error` | TEXT | Nullable |
| `user_message` | TEXT | The user's query |
| `response` | TEXT | Nullable — final pipeline output |
| `user_id` | UUID | Nullable — if authenticated |
| `grade_level` | INTEGER | Nullable |
| `language` | VARCHAR(8) | Nullable |
| `intent` | VARCHAR(32) | Nullable |
| `nodes_visited` | JSONB | List of node names |
| `node_timings` | JSONB | `{"node_name": duration_ms}` |
| `metadata` | JSONB | Flexible: coverage_score, hallucination_rate, groundedness, etc. |
| `duration_ms` | FLOAT | Computed from start/end |

## Components

### `src/core/tracing/trace_repository.py`

Async CRUD class wrapping the SQLAlchemy model:

```python
class TraceRepository:
    def __init__(self, session_factory): ...

    async def save_trace(
        self, trace: PipelineTrace, state: AgentState
    ) -> None

    async def get_trace(self, trace_id: str) -> Optional[dict]

    async def list_traces(
        self,
```

### `src/api/tracing.py`

| Method | Path | Description |
|--------|------|-------------|
| GET | `/traces` | List traces with filters |

### `src/core/monitoring.py` — Wiring

`PipelineMonitor` gets an optional `on_complete` callback:

```python
class PipelineMonitor:
    def __init__(self):
        self.traces: dict[str, PipelineTrace] = {}
        self._on_complete: Optional[Callable] = None

    def set_on_complete(self, callback: Callable) -> None:
        self._on_complete = callback

    async def finalize_trace(
        self, trace_id: str, status: str, state: AgentState
    ) -> None:
        trace = self.traces.get(trace_id)
        if not trace:
            return
        trace.finish(status=status)
        if self._on_complete:
            await self._on_complete(trace, state)
```

At app startup in `src/main.py`:

```python
trace_repo = TraceRepository(session_factory)
pipeline_monitor.set_on_complete(
    lambda t, s: trace_repo.save_trace(t, s)
)
```

## Error Handling

- `TraceRepository` wraps DB errors, logs them, raises `TracingError`
- API returns 404 for missing trace_id
- API returns 400 for invalid filter parameters
- Callback failure is logged but non-fatal — pipeline execution is not affected
