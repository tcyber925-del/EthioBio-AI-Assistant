# Ground Truth Diagram Validation Endpoint

> **Driven by:** US-009 (PRD priority 9)
> **Status:** Design — pending approval

## Problem

The current `/diagram/validate` endpoint accepts `correct_labels` from the frontend (generated by the AI in the same request). This creates a trust issue — the same AI that generated the diagram also provides the "correct" answer. With `ground_truth_labels` now populated on `TextbookDiagram` records (US-007), students can validate against actual textbook labels.

## Approach

Minimal change to the existing validate endpoint. Add `textbook_diagram_id` as an optional field. When provided, load the textbook diagram's ground truth labels and use them as the answer key. When absent, use the existing `correct_labels` from the request.

## Changes

### 1. Schema

**`DiagramValidateRequest`** — add optional field:
```python
class DiagramValidateRequest(SchemaModel):
    user_id: UUID
    correct_labels: list[DiagramLabel]
    submitted_labels: list[DiagramLabel]
    topic: str = Field(..., pattern="^(cells|organ systems|genetics|anatomy)$")
    difficulty: str = Field("beginner", pattern="^(beginner|intermediate|advanced)$")
    textbook_diagram_id: Optional[UUID] = None
```

**`DiagramValidateResponse`** — add source field:
```python
class DiagramValidateResponse(SchemaModel):
    score: float
    total_labels: int
    correct_count: int
    results: list[DiagramLabelResult]
    attempt_id: UUID
    source: str = "ai_generated"  # "textbook" | "ai_generated"
```

### 2. Endpoint Logic

In `src/api/diagram.py`, `validate_diagram()`:

```
if request.textbook_diagram_id:
    diagram = await session.get(TextbookDiagram, request.textbook_diagram_id)
    if not diagram:
        raise 404
    if not diagram.ground_truth_labels:
        raise 400 ("No ground truth labels available for this diagram")
    correct = diagram.ground_truth_labels["labels"]    # list[dict] with id/text/x/y
    source = "textbook"
else:
    correct = [l.model_dump() for l in request.correct_labels]
    source = "ai_generated"

# Same validate_labels() call, same DiagramAttempt save
results = validate_labels(correct, submitted)
...
return DiagramValidateResponse(..., source=source)
```

The `ground_truth_labels` field stores: `{labels: [{id, text, x, y}], proposed: true, human_reviewed: false, model_used: "..."}`. We extract `.labels` from it.

### 3. Error Handling

| Scenario | HTTP Status | Detail |
|----------|-------------|--------|
| `textbook_diagram_id` not in DB | 404 | `"Textbook diagram not found"` |
| Diagram exists but no `ground_truth_labels` | 400 | `"Textbook diagram has no ground truth labels"` |
| `ground_truth_labels.labels` is empty | 400 | Same — no labels available |
| Other DB/validation errors | 500 | Existing catch-all |
