- `src/core/memory/retrieval_orchestrator.py`: RetrievalOrchestrator with `search()` and `search_by_topic()` methods, `MemoryRetrievalResult` data class, composite ranking formula

#### Files Modified
- `src/core/memory/router.py`: Added `POST /memory/search` endpoint, imported `RetrievalOrchestrator` + search schemas
- `src/schemas/memory.py`: Added `MemorySearchRequest`, `MemorySearchResult`, `MemorySearchResponse` schemas

#### Key Decisions
- **Ranking formula**: `final = 0.3*similarity + 0.4*recency + 0.3*confidence` — recency weighted highest to favor recent sessions
- **Recency decay**: Exponential half-life of 14 days (`2^(-age/14)`) — a session from 14 days ago scores 0.5, 28 days ago scores 0.25
- **Token budget**: `estimate_tokens()` uses `len//4` heuristic, truncates results in ranked order when total exceeds 1500
- **Fetch size**: Retrieves 20 results from ChromaDB, re-ranks, returns top-N (default 5)
- **Topic filtering**: ChromaDB `$and` where clause built from optional `topic` + `user_id` params
- **No DB read needed for ranking**: All metadata (confidence, created_at) stored in ChromaDB metadata
