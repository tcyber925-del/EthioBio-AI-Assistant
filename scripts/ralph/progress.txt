## Codebase Patterns
- Socratic mode is a boolean field on AgentState (`socratic_mode: bool`) passed through the LangGraph pipeline
- TutorNode and TutorAgent both accept a `socratic_mode` parameter to switch between standard and Socratic system prompts
- Telegram bot stores session-scoped toggles in `context.user_data`
- API request schemas always default `socratic_mode: bool = False` to maintain backward compatibility
